Harga Modal SKU

Upload file dengan kolom ID SKU dan Harga Modal. Boleh diupload ulang kapan saja untuk menambah SKU baru atau update harga yang sudah ada.

Data Pencairan (CSV dari sheet "Detail pesanan" pada laporan income) — wajib ada kolom: ID Pesanan/Penyesuaian, Jenis transaksi, Waktu pembayaran pesanan, Total Pendapatan, Total Biaya, Jumlah penyelesaian pembayaran, Jumlah penyesuaian, dan kolom rincian biaya (Biaya komisi platform, Komisi dinamis, Biaya layanan cashback bonus, Komisi Afiliasi, Komisi Iklan Toko afiliasi, Biaya pemrosesan pesanan, kolom-kolom Ongkir). Kolom lain akan diabaikan, tidak masalah kalau ikut terbawa.

Data Pesanan (CSV dari daftar pesanan) — wajib ada kolom: Order ID, SKU ID, Quantity, Product Name. Upload data pesanan untuk periode order dibuat yang cukup jauh ke belakang (2–3 bulan sebelum bulan pencairan pertama) supaya order lama yang baru cair tetap ketemu SKU-nya.

Harga Modal SKU — cukup 2 kolom: ID SKU dan Harga Modal. Boleh diupload ulang kapan saja untuk update harga.

File boleh format .csv atau .xlsx langsung, tidak perlu convert manual.

Data disimpan di repo GitHub privat kamu sendiri (lihat Pengaturan Penyimpanan).
